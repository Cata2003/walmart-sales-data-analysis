# Walmart Sales Data Analysis

Proyecto de análisis y procesamiento de datos de ventas de Walmart desarrollado utilizando Python y Pandas.

## Objetivo

Realizar un proceso de limpieza, transformación y análisis exploratorio de datos de ventas con el objetivo de identificar patrones relacionados con ventas, ganancias, productos, categorías, clientes y ubicación geográfica.

## Tecnologías utilizadas

* Python
* Pandas
* Jupyter Notebook
* Excel
* PostgreSQL
* SQL

## Dataset

El dataset utilizado corresponde a **Walmart Sales Dataset**, obtenido desde Kaggle.

* Fuente: Kaggle
* Licencia del dataset: Apache License 2.0
* Archivo original: `walmart.xlsx`

## Procesamiento realizado

Durante el proyecto se realizaron tareas como:

* Exploración inicial del dataset.
* Identificación y tratamiento de datos faltantes.
* Limpieza y transformación de variables.
* Creación de un dataset analítico.
* Análisis de ventas y ganancias.
* Análisis por categorías y productos.
* Generación de archivos procesados para análisis posterior.

## Archivos principales

* `Walmart_Sales_Data_Analysis.ipynb`: notebook con el desarrollo completo.
* `walmart.xlsx`: dataset original.
* `dataset_analitico_walmart.xlsx`: dataset procesado y preparado para análisis.
* `resumen_categoria_walmart.xlsx`: resumen de resultados por categoría.
